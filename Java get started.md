# Java Syntax
La sintaxis de Java son las reglas que se deben seguir para escribir correctamente un programa. El codigo debe estar dentro de una clase, utilizar llaves para organizar las instrucciones y terminar cada sentencia con punto y coma (;). Tambien se utiliza el metodo `main()` para iniciar la ejecucion del programa.

public class Main {
  public static void main(String[] args) {
    System.out.println("Hello World");
  }
}

# Java Output
Java Output sirve para mostrar mensajes, textos y numeros en la pantalla. Para poder hacerlo se utiliza principalmente `System.out.println()`, nos muestra la informacion y pasa a la siguiente linea, y `System.out.print()`, y permite mostrarla en la misma linea.

System.out.println("Hello World!");

# Java Comments

Los comentarios en Java sirven para escribir notas o explicaciones dentro del codigo. No se ejecutan ni afectan el funcionamiento del programa, sino que ayudan a entender mejor las instrucciones. Se utilizan `//` para comentarios de una linea y `/* */` para comentarios de varias lineas.


System.out.println("Hello World");
